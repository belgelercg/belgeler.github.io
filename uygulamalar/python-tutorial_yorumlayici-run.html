Yorumlayıcının Çalıştırılması
Python yorumlayıcısını Linux Konsolunda ya da xterm'de python komutunu girerek çalıştırabilirsiniz. Python yorumlayıcısının konsolda çalışanı olduğu gibi X Pencere Sisteminde çalışanı da vardır. X pencere sisteminde çalışan yorumlayıcı idle komutu ile çalıştırılabilir. Menüleriyle kolay kullanılabilen bir Python düzenleyicisidir ve konsolda çalışan python gibi "Python Kabuğu" penceresinde doğrudan komut icra edilebilir.
python çalıştırıldığında yorumlayıcı konsolda etkileşimli kipte çalışır. Yorumlayıcı çalıştırılacak olan Python programının dosya adı parametre şeklinde verilerek de kullanılabilir. Örneğin python deneme.py gibi.
