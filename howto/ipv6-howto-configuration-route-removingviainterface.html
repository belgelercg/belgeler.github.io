Bir arabirim üzerinden IPv6 rotası kaldırmak
Genellikle elle yapılması gerekmez. Bu işlem kapanış sırasında yapılandırma betikleri tarafından yapılır.
ip kullanarak
Kullanım:
/sbin/ip -6 route del ipv6ağı/önek_uzunluğu dev aygıt
Örnek:
# /sbin/ip -6 route del 2000::/3 dev eth0
route kullanarak
Kullanım:
/sbin/route -A inet6 del ipv6ağı/önek_uzunluğu dev aygıt
Örnek:
# /sbin/route -A inet6 del 2000::/3 dev eth0
