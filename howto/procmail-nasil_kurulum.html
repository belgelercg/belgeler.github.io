Programı kuralım
İndirdiğimiz paket procmail-3.22.tar.gz olsun. Aşağıdaki adımları gerçekleştirelim. Programı açıyor ve yüklüyoruz. make install komutunu vermeden önce Makefile dosyasını açıp istediğiniz yapılandırmayı kullanabilirsiniz.Ben öntanımlı olanları kullanıyorum. 
# mv  procmail-3.22.tar.gz  /usr/local
# cd  /usr/local
# tar  -zxvf  procmail-3.22.tar.gz
# cd  procmail-3.22
# make install
Programın yüklendiğinden emin olalım. 
# procmail -v
Komut aşağıdaki çıktıyı veriyor.
