Kaynak Kodu Dizinlerinin Hazırlanması
TimeSys Linux çekirdeğini derlemeden önce, kaynak dizinini sisteminizdeki tüm sürücülerin ve diğer şeylerin çekirdek tarafından bilinmesi için ayarlamanız gerekir. Bunu aşağıdaki komutlarla yapabilirsiniz: 
# cd /usr/src
# mv linux linux.old   # Sadece önceden linux dizini varsa gereklidir
# mv linux-2.4 linux-2.4.old
# ln -s /opt/timesys/linux/4.1/x86bsp/src/2.4.21-timesys-4.1/kernel linux
# ln -s /opt/timesys/linux/4.1/x86bsp/src/2.4.21-timesys-4.1/kernel linux-2.4
Yukarıdaki komutlarda x86bsp bölümünü ve TimeSys Linux paketinin sürüm numarasını değiştirmeniz gerekebilir.
