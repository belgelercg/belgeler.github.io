Kurulum için gereksinimler
Gerçi güncel Linux sürümlerinin hiçbirinde böyle bir sorun çıkacağını sanmıyorum ama NVIDIA sürücülerini kurmak için gerekli olan önkoşulları kısaca önbilgi olması açısından hatırlatmakta yarar var.
Kısaca en azından gerekli olanları sıralamak gerekirse:
linux kernel 2.2.12
# cat /proc/version
XFree86 4.0.1
# XFree86 -version
Kernel modutils 2.1.121
# insmod -V
binutils 2.9.5
# size --version
GNU make 3.77
# make --version
gcc 2.91.66
# gcc --version
Bu paketlerin sisteminizde kurulu olması gerekmektedir. En yeni Linux sürümlerinde bu programların daha yeni sürümlerini bulabileceğiniz için burayı kafanıza takmanıza gerek yok.:-)
