Windows'ların Samba sunucusuna bağlanması
İlk iş, Windows'ları "domain logon" işlemini olmadan Samba'ya bağlanmak olacak. Ondan önce, indirdiğiniz nexus.exe dosyasını /export/depo dizinine koyun, bağlandığınızda onu oradan alıp kuracaksınız ve ondan sonra "domain logon" işlemi yani ilk oturumu makinanın açtığı işlem devreye girebilecek.
Şimdi Windows kurulu makinalardan birinin başına geçin ve aşağıdaki işlemleri yapın. Benim kullandığım w98 ingilizce olduğundan yanlarında ingilizce terimlerin türkçe karşılıklarını da vereceğim ama Windows türkçesi ile tam uyumlu olmayabilir.
  1. Network Neighborhood [Ağ Komşuları] simgesine farenin sağ tuşu ile tıklayın.
  2. Açılan menüden Properties'e [Özellikler] tıklayın.
  3. Açılan pencerede Identification [Kimlik Bilgileri] sekmesine tıklayın ve alanları aşağıdakine benzer şekilde doldurun: 
    Computer name [Makina ismi]: BELMA
Workgroup [Çalışma Grubu]: LAB
Computer Description [Açıklama]: Windows 98 workstation
  4. Access Control [Erişim Denetimi] sekmesine tıklayın ve burada Share-level access control [Paylaşım seviyesinde erişim denetimi] düğmesini seçili duruma getirin.
  5. Configuration [Yapılandırma] sekmesine tıklayın ve listeden Client for Microsoft Networks [Microsoft Ağları için İstemci] satırını seçin ve Properties [Özellikler] düğmesine tıkayın.
  6. Log on to Windows NT domain [Windows NT alanına Bağlan] kutucuğunu işaretli duruma getirin ve Windows NT domain alanına LAB yazın. Windows NT alanına yani bizim sistemimiz için Samba sunucuya makinanın oturum açmasını sağlayacak olan bu bölümde yapılan işlemdir. Ancak nexus.exe kurulumunu yapıldıktan sonra bu yapılandırma bir işe yarayacak. Şimdilik bir hükmü yok.
  7. Network logon options [Ağ oturumu seçenekleri] bölümünde ise Logon and restore network connections [Oturumu aç ve ağa bağlan] düğmesini seçili duruma getiriyoruz ve OK'e [TAMAM] basıp çıkıyoruz.
  8. Yine listeden Ağ kartının TCP/IP ayarları satırını seçiyoruz ve Properties yani Özellikler düğmesine tıklıyoruz.
  9. Gateway [Ağ Geçidi] sekmesinde New gateway [Yeni ağ geçidi] alanına 10.10.10.254 yazıp Add [Ekle] düğmesine tıklıyoruz.
  10. Wins Configuration [Wins Yapılandırması] sekmesine tıklayıp, En alttaki Use DHCP for WINS Resolution [WINS çözümlemesi için DHCP kullanılsın] düğmesini seçili duruma getiriyoruz. Eğer bu seçenek erişilebilir değilse, IP Address sekmesinden Obtain an IP address automatically [IP adresini özdevinimli al] düğmesini seçili duruma getirdikten sonra geri dönüp DHCP ile bağlanma işlemi yapıyoruz.
  11. Buradaki işimiz bu kadar. OK düğmesine tıklayıp buradan çıkıyoruz.
  12. Son olarak Primary Network Logon [Birincil Ağ Oturumu] alanında listeden Windows Logon'u [Windows Oturumu] seçtikten sonra OK düğmesine tıklıyoruz. Bu noktada Windows sizden yeniden başlatılmayı talep edecektir. İzin verin, yapsın.
Sistem açıldığında kullanıcı ismi ve parola istenen alana bir isim yazın, parola isteğe bağlı. Yazacağınız ismin Linux üzerinde tanımlı olması gerekmiyor. Her kullanıcı Windows üzerinde kendine bir isim seçip onunla bağlanmakta özgür. Ancak tek yapMAMAsı gereken Cancel [İptal] düğmesine tıklamak. O zaman kullanıcı Sambaya bağlanamayacaktır. OK düğmesine tıklayıp oturum açıldığında Samba üzerindeki paylaşımları Windows Explorer [Dosya Yöneticisi]nde Ağ komşularının altındaki NILGUN adı altında görüyor olacaksınız. Eğer göremiyorsanız oturumu sonlandırıp, aynı kullanıcı ismiyle tekrar sisteme giriş yapın (makinayı yeniden başlatmayacaksınız sadece kullanıcının oturumdan çıkmasını sağlayacaksınız -- Windows türkçesini bir türlü öğrenemedim...)
Daha önce Linux sistemindeki /export/depo dizinine koyduğumuz nexus.exe dosyası depo paylaşımı altında sizi bekliyor olacak. Onu c:\temp dizinine kopyalayıp orada çalıştırın. İçinden bir sürü dosya çıkacak. Sırayla Start [Başlat] -> Settings [Ayarlar] -> Control Panel [Denetim Masası] menü alanlarına tıklayın. Add/Remove Programs [Program Ekle/Kaldır]'a tıklayın. Açılan pencerede önce Windows Setup [Windows Kurulumu] sekmesine sonra da Have Disk [Diski Var] düğmesine tıklayın. Dosya araması ile c:\temp dizine gidin, oradaki tek .inf dosyası olan Srvtools.inf dosyasını kendi bulacak. Tamam'a tıkladığınızda kurulum gerçekleşecek. Bundan sonra makinayı yeniden başlattığınızda Samba'ya gayet hızlı bir biçimde bağlanacak ve paylaşımları göreceksiniz. nexus.exe paketinden çıkan uygulamalar bu yapılandırma altında beklendiği gibi çalışmayacaktır. Böylesi daha iyi aksi takdirde Linux makinasındaki tüm kullanıcılar (gizli sistem kullanıcıları dahil) görüntüleniyor.
Bu işlemleri her makinaya farklı isimler vererek tekrarlayın. İşlemler bittiğinde Windows ağınız kullanıma hazır olacak.
Ağa sunucu olarak Linux üzerinde Samba'yı yerleştirip ağı tekrar çalışır duruma getirdiğinize göre artık, X terminallerinizi yapılandıracak işlemlere başlayabilirsiniz. Bunların o kadar acelesi olmayacaktır. Önce donanımları aynı olan makinalarla başlar, sonra diğer makinalara zaman içinde uygularsınız. Sunucu makinayı artık X terminallerine hizmet verecek şekilde yapılandırmaya başlayabiliriz.
