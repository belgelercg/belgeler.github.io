IPv6 Adreslerini Kaldırmak
Pek sık ihtiyaç duyulmaz ama varolmayan IPv6 adreslerinin kaldırılması eski çekirdeklerde sistemin çökmesine neden olabileceğinden dikkatli kullanılmalıdır.
ip kullanarak
Kullanım:
/sbin/ip -6 addr del ipv6adres/önek_uzunluğu dev arabirim
Örnek:
# /sbin/ip -6 addr del 3ffe:ffff:0:f101::1/64 dev eth0
ifconfig kullanarak
Kullanım:
/sbin/ifconfig arabirim inet6 del ipv6adres/önek_uzunluğu
Örnek:
# sbin/ifconfig eth0 inet6 del 3ffe:ffff:0:f101::1/64
