ISO-8859-9 Konsol Alt-Q klavye dosyası (trqalt.kmap)
Aşağıdaki metni bir metin düzenleyici içine kopyaladıktan sonra /lib/kbd/keymaps/i386/qwerty/ dizini altına trqalt.kmap ismiyle kaydedin. Az yer kaplaması için komut satırına gzip trqalt.kmap yazarak dosyayı sıkıştırabilirsiniz. 
# trqalt.kmap by Baurjan Ismagulov <ibr@gantek.com>
# $Id: trqalt.kmap,v 1.6 2002/03/02 23:20:22 ibr Exp $
#
# Based on defkeymap.
# Same as defkeymap, with Latin5-encoded Turkish letters accessible via
# AltGr. Unlike in tralt, Turkish letters are on their usual places (as
# in Turkish Q layout).
#
# AltGr-3 is dead_circumflex for [auiAUI].
# AltGr-[auAU] produce [auAU]circumflex.
# AltGr-Shift-I produces icircumflex.
#
# Added "euro" support for consistency -- ro <roktas@omu.edu.tr>

charset "iso-8859-9"
keymaps 0-15
strings as usual
compose as usual for "iso-8859-1"
include "euro"
