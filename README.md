# belgeler.org.tr

Bu sayfalar 2001-2026 yılları arasında Sourceforge tarafından sunuluyordu.
Artık Github tarafından sunulacak. Bu taşınmanın sebebi, son zamanlarda Sourceforge 
sunucusunun proje sayfalarına `https` desteği vermemesi ve bunun sonucunda
tarayıcıların siteyi güvensiz bularak içeriği okumamasıydı. Yani, Sourceforge
 `belgeler.org.tr`'yi aslında sunmuyordu. Ziyaretçiler Sourceforge'un uygulaması
sonucu kapıdan dönüyordu. 

Zaten bir süre önce içerik alt yapısını Github'a taşımıştık (`github.com/tlbp`). 
Çalışmaların sonucunu `tlbp.org.tr` altında sınıyor ve sunuyorduk. Yalnızca 
çalışmaları tamamlanan içerik `belgeler.org.tr`'ye aktarılıyordu.

`tlbp.org.tr` sitemizin, tarayıcıların `https` hışmına uğramadığını farkedince
`belgeler.org.tr` sitesini de Github'a taşıdık. Bundan sonra `belgeler.org.tr`
ziyaretçilerinin siteyi sorunsuzca ziyaret edebileceklerini umuyoruz.  
 
Sourceforge proje sayfamız duracak ama artık dokunmayacağız. 22 Kasım 2026
